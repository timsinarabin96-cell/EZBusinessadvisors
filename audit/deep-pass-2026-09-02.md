## Recommendations (enterprise/best-in-class)

1. **Fix the franchise validation gaps** (S3-adjacent): min>0 checks on all
   numeric franchise fields; reject non-numeric input instead of nulling.
2. **Decide + enforce franchise usage-limit policy** (exempt or counted).
3. **Self-host fonts** (Inter/Space Grotesk) — removes third-party font
   dependency + the Firefox download errors + privacy leak of IPs to Google.
4. **Add skip-to-content + aria labels** across the shell; run axe-core in
   CI on every e2e page.
5. **WebKit testing**: add a CI matrix (GitHub Actions) with Playwright
   webkit/firefox so cross-browser is covered outside this VPS.
6. **Idempotency keys** on public write endpoints (franchise POST,
   seller-order) to make retries/concurrent submits safe.
7. **Staged load test of the paid pipeline** before major promotion
   (simulate N concurrent paid sellers).
8. **Stripe test-mode harness**: a scripted end-to-end (checkout → webhook →
   auto-publish) so the paid paths are regression-tested without real money.
9. **Centralize agency-resolution** for all self-serve write routes
   (franchise POST, seller-order) into one helper with the authz rules, so
   future endpoints can't reintroduce the S1 class of bug.
10. **Audit log for RE-closing completions** (who marked it done + which
    license number was attached) — good for the brokerage's own liability
    posture.
