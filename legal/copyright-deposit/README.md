## What registration gives you

- Right to sue in federal court for infringement.
- **Statutory damages** up to $150,000 per work for willful copying + attorney's fees.
- Public record of ownership (proves the claim against copycats).
- Note: registration within 3 months of publication makes statutory damages
  retroactive. The site launched ~July 2025, so that window has passed for the
  original content — register NOW anyway; it protects everything going forward
  and is required before you can sue at all.

## Timing

- Electronic registration processing is typically several months.
- Expedited service exists (~$800+) if you ever need it urgently.
- File the code and website as two separate applications (they're different
  work types). The logo can be a third, optional, under Visual Arts.
